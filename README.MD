# RIWI User Stories

**Author:** Jose Romero

This repository contains the evidences related to the **User Stories from the RIWI program**.

The materials are taken from the **RIWI Moodle platform** and uploaded here before being submitted to Moodle.
The repository may include different types of files such as **scripts, PDFs, or other evidence files**.

## Naming Convention

Files are organized using the following format:

mXwY

Where:

* **mX** = month of the program
* **wY** = week of that month

Example:

* m1w1
* m1w2
* m2w1

## Purpose

* Keep a personal backup of the activities
* Organize RIWI evidence by month and week
* Track progress during the program
